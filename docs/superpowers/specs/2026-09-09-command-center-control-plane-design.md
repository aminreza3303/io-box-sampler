# مقر فرماندهی — طراحی Control Plane محصول

## هدف

تبدیل مقر فرماندهی از مجموعه‌ای از صفحات پراکنده به یک control plane فارسی و وب‌محور برای دانش محصول، AI، فرایندهای اجرایی، کنترل‌های مالی و مدیریت دسترسی.

## تجربهٔ کاربر

- همهٔ متن‌های رابط فارسی، کوتاه، عملیاتی و با واژه‌نامهٔ ثابت هستند.
- فونت فارسی در bundle خود برنامه قرار می‌گیرد تا به CDN وابسته نباشد.
- `/domains` مانند یک canvas وب عمل می‌کند: سایدبار جست‌وجو، فضای گراف با zoom و کارت‌های متصل، inspector دامنه و نقشهٔ راه.
- Obsidian فقط منبع تاریخی artifact است و از UI وب حذف می‌شود؛ کاربر هیچ برنامهٔ دیگری برای استفاده از نقشه لازم ندارد.

## لایه‌های جدید

- AI Workspace: چت با Hermes مادر با context پروژه/دامنه/فرایند؛ هر run و message در دیتابیس ذخیره می‌شود؛ پاسخ‌های اجرایی به proposal تبدیل می‌شوند و بدون تأیید مدیرعامل اعمال نمی‌شوند.
- عملیات: فرایندهای KYC، کارت، انتقال، QR، شارژ، سفارش و پشتیبانی با step، مالک، کنترل و وضعیت.
- مالی: کیف چندارزی، FX، سقف‌ها، وام، طلا، بیمه و تسویهٔ پذیرنده به‌صورت cockpit کنترل‌محور و خواندنی.
- ادمین: ماتریس نقش/مجوز، وضعیت agentها، سقف‌ها، metrics و audit trail.

## مدل فنی

- تعریف‌های فرایند در `lib/workspaces.ts` به‌صورت دادهٔ typed نگهداری می‌شوند و UI موازی برای هر بخش ساخته نمی‌شود.
- `AgentRun` و `AgentMessage` برای تاریخچهٔ AI اضافه می‌شوند.
- routeهای AI احراز هویت می‌شوند، context محدود دارند و خطای runtime را صادقانه به کاربر نشان می‌دهند.
- دادهٔ مالی این مرحله ادعای ledger واقعی ندارد؛ در UI با برچسب «کنترل/پیشنهاد» نمایش داده می‌شود.
