# Vault محلی نقشهٔ محصول نیوکاش

این پوشه یک بستهٔ آفلاین برای Obsidian است و هیچ اتصال ابری یا سرویس خارجی ندارد.

## باز کردن

1. Obsidian را نصب و باز کنید.
2. گزینهٔ **Open folder as vault** را بزنید.
3. همین پوشهٔ `docs/obsidian/newcash-vault` را انتخاب کنید و نام vault را `newcash` بگذارید.
4. فایل `newcash-map.canvas` را باز کنید.
5. برای توضیح مرحله‌به‌مرحله، `نقشه-راه-بازسازی-نیوکاش.md` و برای فهرست دامنه‌ها، `دامنه‌ها/00-فهرست-دامنه‌ها.md` را باز کنید.

صفحهٔ وب مقر فرماندهی نیز همین map را در مسیر `/domains` به‌صورت تعاملی نمایش می‌دهد. فایل Canvas و Markdown نسخهٔ قابل ویرایش محصول‌اند؛ تغییرات مهم را در git commit کنید.

## قواعد پایه

- W-1: کیف پول به‌ازای هر ارز است؛ ارز داده است، نه کد.
- S-1: ارز خدمت برابر ارز تسویهٔ تأمین‌کننده است.
- L-1: سقف‌ها دادهٔ قابل ویرایش‌اند، نه مقدار hard-code.
- P-1: نقش مجموعه‌ای از مجوزهای فعل + شیء است.
- P-2: هر اعمال حساس باید audit trail داشته باشد.

## ساختار

- `newcash-map.canvas`: نقشهٔ گرافی دامنه‌ها و edgeهای وابستگی.
- `نقشه-راه-بازسازی-نیوکاش.md`: ترتیب پنج گام از کشف تا اکوسیستم.
- `دامنه‌ها/00-فهرست-دامنه‌ها.md`: inventory، وضعیت، اولویت و قالب کارت دامنه.
